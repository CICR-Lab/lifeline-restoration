# Module 03 - Hierarchical Repair Model

## 1. Overview

This module implements the hierarchical repair model and its analytical,
simulation and interdependent-network components. It supports:

- main-text Figure 4b-h;
- Supplementary Figures S13-S18;
- the Inputs sheet of Supplementary Table S8.

The module uses the empirical restoration source data exported by Module 02.

## 2. Requirements

- MATLAB with Optimization Toolbox for restoration-shape fitting with
  `lsqcurvefit`.
- Statistics and Machine Learning Toolbox.
- Parallel Computing Toolbox is optional. Full simulations use parallel
  execution when available and otherwise run serially.
- The frozen empirical input from Module 02.

## 3. Inputs

### Upstream input

```text
../02_EmergentSimplicity/figure_data/main/SourceData_Figure3.xlsx
```

### Generated calculation inputs

The model configuration and design are generated by the code for the selected
execution mode. Restartable checkpoints and scenario caches are generated
during a run to support resuming calculations.

### Frozen figure inputs

The distributed `figure_data/full/` directory contains the MAT, CSV and XLSX
files required by the full-mode plotting entry points. These files allow the
formal figures to be redrawn without rerunning the analytical and simulation
calculations.

## 5. Running the module

### Full publication workflow

Change MATLAB to the `03_HierarchicalRepairModel` directory and run:

```matlab
run_hierarchical_repair_analysis('full')
run_figure_4('Mode','full','DataSource','generated')
run_supplementary_hierarchical_repair_model('Mode','full','DataSource','generated')
```

The analysis entry point computes the analytical, simulation and
interdependent results, exports generated direct figure inputs under
`outputs/figure_data/full/` and writes the source data for Supplementary Table
S8. In this full workflow, the plotting entries read the generated inputs from
the analysis just completed.

### Redraw retained full-mode figures

To redraw the retained full-mode inputs without rerunning the calculations:

```matlab
run_figure_4('Mode','full','DataSource','packaged')
run_supplementary_hierarchical_repair_model('Mode','full','DataSource','packaged')
```

These calls read only `figure_data/full/`.

### Quick workflow

For a software and layout check, run the same sequence with `quick`:

```matlab
run_hierarchical_repair_analysis('quick')
run_figure_4('Mode','quick','DataSource','generated')
run_supplementary_hierarchical_repair_model('Mode','quick','DataSource','generated')
```

The quick mode uses the same equations and scenario definitions with fewer
samples and replicates for software and layout validation. The full mode
produces publication results. Quick-mode figures are written to
`outputs/validation/quick_figures/`; formal figures are saved under
`outputs/figures/`.

### Partial reruns

The calculation and plotting entry points can be rerun separately when the
corresponding inputs already exist. `DataSource='packaged'` reads only the
retained files in `figure_data/<mode>/`; `DataSource='generated'` reads only
`outputs/figure_data/<mode>/` and therefore follows the selected analysis run.
`DataRoot` can be supplied when a selected direct figure-data folder is stored
elsewhere, and `OutputDir` can redirect the rendered `main/` and
`supplementary/` subdirectories. Compatible checkpoints and scenario caches
are reused automatically.

## 7. Reproducibility notes

- `full` is the publication mode. `quick` is a software and layout check only.
- Simulation checkpoints and interdependent caches carry experiment or
  scenario signatures and algorithm versions. Compatible files can be reused;
  incompatible files are recomputed.
- For a clean rerun, remove only the selected mode under `outputs/` and its
  corresponding `outputs/figure_data/<mode>/` directory. Packaged plotting
  reads the retained files in `figure_data/full/`; generated
  plotting uses the regenerated files in `outputs/figure_data/<mode>/`.
- Formal figures use full-mode results. Quick-mode figures are validation
  outputs and are kept separate from the formal figure directories.
- `outputs/` stores regenerable calculations, checkpoints and rendered figures.
  It is empty in the release package and is populated when a workflow is run.
- The empirical source workbook is versioned upstream in Module 02. If it
  changes, recalculate this module and regenerate its figure-data exports.
- Numerical results depend on the configured sample sizes, replicate counts,
  random streams and the available MATLAB toolboxes.
